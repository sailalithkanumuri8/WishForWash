# Photo credits

Place and campus photos used on Wish for Wash. Every image comes from Wikimedia Commons
under a free license or is in the public domain. Each one was cropped to 3:2, resized to
960x640 and tinted with a light-blue duotone (75% duotone, 25% original colour) by
`tools/process-photos.py`. The same data, in machine-readable form, is in
`data/photo-credits.json`.

Our modified versions of CC BY-SA photos are shared under the same CC BY-SA license.

## Notes

- `stamps-field`: Wikimedia Commons has no photo of Stamps Field itself, so this slot uses
  Burger Bowl, another Georgia Tech recreation field.
- `proctor-creek`: the source file says "Rockdale GA"; it was taken in Atlanta's Rockdale
  neighborhood on the Westside (Commons category "Rockdale, Atlanta"), not Rockdale County.

## Not included

- `ecocommons`: Wikimedia Commons has no photo of the Georgia Tech EcoCommons, and no
  federal public-domain image of it was found, so no image was made.

## Reproducing the images

Originals were downloaded from the source pages above (the Kendeda and Clough photos as
Commons' 3840-pixel-wide renditions). Each output was made with

```
python3 tools/process-photos.py ORIGINAL assets/img/<places|campus>/<id>.webp [options]
```

| id | options | size |
| --- | --- | --- |
| midtown-atlanta | `--focus 0.33,0.55 --zoom 1.12` | 106.1 KB |
| proctor-creek | `--focus 0.45,0.66 --zoom 1.2 --gamma 1.35 --contrast 0.3 --soften 0.7` | 99.3 KB |
| lake-lanier | no options: full frame, already 3:2 | 89.5 KB |
| albany-flint | no options: full frame, already 3:2 | 95.2 KB |
| coast | no options: centred 3:2 crop | 109.2 KB |
| middle-georgia | `--focus 0.475,0.5 --zoom 1.06 --contrast 0.4` | 100.3 KB |
| kendeda | `--focus 0.535,0.5` | 95.8 KB |
| stamps-field | `--focus 0.5,0.53 --gamma 0.85 --contrast 0.3` | 109.7 KB |
| cisterns | `--focus 0.5,0.5 --gamma 0.85` | 82.1 KB |
